feat: add IBM Bob as a provider and coding-agent host

Set `OPENWIKI_PROVIDER=bob` with a `BOB_API_KEY` inference key to use IBM Bob's
hosted Claude models. Run `openwiki integrations install bob` to configure the
MCP server in `~/.bob/mcp.json` and install the OpenWiki skill bundle under
`.agents/skills/openwiki`.
