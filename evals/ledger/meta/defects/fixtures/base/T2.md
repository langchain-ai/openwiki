# calc 2.0.0

- calc is a TypeScript arithmetic library.
- The library provides add(a, b), which returns the sum a + b.
- The library provides subtract(a, b), which returns the difference a - b.
- Arithmetic operations use JavaScript number semantics, are pure, and perform no input validation, rounding, or I/O.
- The library's current version is 2.0.0.
